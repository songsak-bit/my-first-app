# attendance

หน้าเว็บลงชื่อออนไลน์ ใช้บนมือถือได้ แต่ละคนเข้าสู่ระบบด้วยอีเมล ลงชื่อ และเห็นเฉพาะประวัติการลงชื่อของตัวเอง

- หน้าเว็บ: https://songsak-bit.github.io/my-first-app/
- ข้อมูลทั้งหมดอยู่ใน Google Sheet แท็บ `data` คอลัมน์ timestamp, name, note, email

## ไฟล์

- `index.html` หน้าเว็บ (เปิดผ่าน GitHub Pages)
- `Code.gs` สคริปต์ Google Apps Script ที่รับการล็อกอิน การลงชื่อ และส่งประวัติ

## การเข้าสู่ระบบ

1. ใส่อีเมล แล้วกด "ส่งรหัสเข้าสู่ระบบ"
2. สคริปต์ส่งรหัส 6 หลักไปที่อีเมลนั้น (ใช้ได้ 10 นาที ใส่ผิดได้ 5 ครั้ง)
3. ใส่รหัสถูก จะเข้าสู่ระบบได้ 6 ชั่วโมงบนเครื่องนั้น

ความปลอดภัย

- รหัสและ session เก็บเป็นค่าแฮช (SHA-256) ใน CacheService เท่านั้น และหมดอายุเอง
- ขอรหัสได้ทุก 60 วินาที และไม่เกิน 5 ครั้งต่อชั่วโมงต่ออีเมล
- หน้าเว็บไม่มีทางดึงรายชื่อของคนอื่นได้ ประวัติจะส่งให้เฉพาะเจ้าของอีเมลที่ล็อกอินอยู่
- ผู้ดูแล (เจ้าของชีต) ดูรายชื่อทั้งหมดได้ในชีตตามปกติ

จำกัดให้ล็อกอินได้เฉพาะอีเมลบางโดเมน: แก้บรรทัดนี้ใน `Code.gs`

```js
const ALLOWED_DOMAINS = ["coolinnotech.com"];
```

## ตั้งค่า / อัปเดตสคริปต์

1. เปิดชีต > **Extensions > Apps Script** ลบโค้ดเดิม แล้ววางโค้ดจาก `Code.gs` กด Save
2. ด้านบนเลือกฟังก์ชัน **authorize** แล้วกด **Run** 1 ครั้ง กดอนุญาตสิทธิ์ (ส่งอีเมลและแก้ชีต)
3. **Deploy > Manage deployments** > ไอคอนดินสอ
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Version: **New version**
   - กด Deploy (URL เดิมยังใช้ได้)

ถ้าสร้าง deployment ใหม่และได้ URL ใหม่ ให้แก้ `SHEET_URL` ใน `index.html`

## ข้อจำกัด

- บัญชี Gmail ทั่วไปส่งอีเมลจาก Apps Script ได้ประมาณ 100 ฉบับต่อวัน (บัญชี Google Workspace ได้มากกว่า) แต่ละการล็อกอินใช้ 1 ฉบับ
- อีเมลรหัสส่งจากบัญชีเจ้าของชีต
