# attendance

หน้าเว็บลงชื่อออนไลน์ ใช้บนมือถือได้ มีช่องชื่อ ช่องหมายเหตุ ปุ่ม "ลงชื่อ" และรายชื่อคนที่ลงชื่อแล้ว

## ไฟล์

- `index.html` หน้าเว็บ (เปิดผ่าน GitHub Pages)
- `Code.gs` สคริปต์สำหรับ Google Sheets ใช้เป็นที่เก็บรายชื่อกลาง

## โหมดการเก็บรายชื่อ

GitHub Pages เป็นเว็บแบบ static ไม่มีที่เก็บข้อมูลกลาง จึงมี 2 โหมด

1. **เก็บในเครื่อง** (ค่าเริ่มต้น) รายชื่ออยู่ในเบราว์เซอร์ของเครื่องที่เปิดเท่านั้น เหมาะกับการวางมือถือหรือแท็บเล็ตเครื่องเดียวไว้ให้คนมาลงชื่อ
2. **Google Sheets** ทุกเครื่องเห็นรายชื่อชุดเดียวกัน และรายชื่อไปอยู่ในชีตด้วย

## เชื่อมกับ Google Sheets

1. สร้าง Google Sheet ใหม่
2. ไปที่ **Extensions > Apps Script** ลบโค้ดเดิม แล้ววางโค้ดจาก `Code.gs`
3. กด **Deploy > New deployment** เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด Deploy แล้วอนุญาตสิทธิ์ คัดลอก URL ที่ลงท้ายด้วย `/exec`
5. เปิด `index.html` แก้บรรทัด

   ```js
   const SHEET_URL = "";
   ```

   ใส่ URL ที่คัดลอกมาไว้ในเครื่องหมายคำพูด แล้ว commit

หน้าเว็บจะดึงรายชื่อใหม่ทุก 10 วินาที การลบรายชื่อในโหมดนี้ให้ลบแถวในชีตโดยตรง
